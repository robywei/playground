# `git:commit` 的本 repo 專屬規則

由 repo-template 產生一次，之後**歸本 repo 維護**，範本 update 不會覆蓋這個檔案。
共用流程在 [`git:commit`](../skills/git/skills/commit/SKILL.md)；這裡只寫**只在本 repo 成立**的規則，例如：

- Code Review 時本 repo 特有的高頻缺陷
- 文件該寫在哪些目錄（本 repo 的 `README.md` / `docs/` 佈局）
- 改到會立即影響線上的路徑，以及為什麼危險
- 本 repo 的實際案例

本 repo 目前沒有專屬規則。
