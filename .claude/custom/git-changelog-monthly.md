# `git:changelog-monthly` 的本 repo 專屬資訊

由 repo-template 產生一次，之後**歸本 repo 維護**，範本 update 不會覆蓋這個檔案。
共用流程在 [`git:changelog-monthly`](../skills/git/skills/changelog-monthly/SKILL.md)；這裡記錄本 repo 歸檔檔的歷史，例如：

- `docs/history/archive/` 底下有哪些年度檔、各涵蓋哪些月份
- 導入 git-cliff 時搬入了多少手寫紀錄、格式有什麼不同
- 本 repo 發生過的歸檔事故

本 repo 目前沒有專屬資訊。
