# `.claude/skills/` 的本 repo 專屬資訊

由 repo-template 產生一次，之後**歸本 repo 維護**，範本 update 不會覆蓋這個檔案。
共用的佈局慣例在 [`.claude/skills/README.md`](../skills/README.md)、命名與退場在 [`lifecycle.md`](../skills/lifecycle.md)；
這裡只寫**只在本 repo 成立**的資訊，例如：

- 本 repo 各 domain 的用途與範圍（哪類情境該進哪個 domain、哪些刻意不在本 repo）
- 寫 skill 時的本 repo 慣例（例如範例一律用哪個環境、哪些已退役的環境不再新增 skill）
- 刻意不照共用佈局的例外，以及為什麼
- 待補情境（skill backlog）：想到但還沒寫的情境，與觸發它的場合

skill 清單不要寫在這裡 —— 用 README 的查詢指令，或看 session 啟動時注入的 description。

本 repo 目前沒有專屬規則。
