# `git:changelog` 的本 repo 專屬資訊

由 repo-template 產生一次，之後**歸本 repo 維護**，範本 update 不會覆蓋這個檔案。
共用流程在 [`git:changelog`](../skills/git/skills/changelog/SKILL.md)；這裡記錄只在本 repo 成立的情況，例如：

- 有沒有每日排程代為生成 CHANGELOG（排程在哪、失敗時去哪查 log）
- 哪些來源會在作業期間推進 `main`（CI 的版本更新 commit、排程、本機的自動 pull）
- 有哪些 bot / CI 會 commit、主旨帶不帶 `[skip ci]`、本 repo 有沒有 push 觸發的 workflow
- 本 repo 發生過的生成事故

本 repo 目前沒有專屬資訊。
